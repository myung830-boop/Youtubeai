**입체감을 내는 장치 6가지** (이번 편에서 새로 만들 것)
1. **3D 휴대폰** — 두께·측면·그림자가 있는 휴대폰을 회전 (CSS 3D)
2. **휴대폰 속으로 들어가기** — 카메라가 화면 안으로 돌진하면서 다음 장면으로 전환
3. **3D 카드 회전목마** — 사례 5장이 원형으로 돌다가 하나가 앞으로 (S06 시작)
4. **누운 휴대폰 위로 세워지는 탭** — 스카이뷰에서 4개 메뉴가 카드처럼 일어섬 (S05)
5. **깊이 3층 사진** — 뒤(실사 흐림) / 가운데(사장님) / 앞(소품·카드) `Parallax`
6. **시계 되감기** — 실사 시계 위 바늘이 거꾸로 돌고 '할 일 카드'가 날아가며 시간 칩이 돌아옴 (엔딩)

## 3. 피클 브랜드 (트레이드마크) 표현
- 레지스트리에 `pickle` 등록 → 썸네일 배지, 장면 제목 칩, 채팅 화면 상단바, 로고 리빌, 허브 중앙에 사용
- **공식 로고·앱 아이콘·색을 아직 확보하지 못함** (pickle.com·앱스토어가 이 작업 환경에서 열리지 않음)
  → 지시서 원칙대로 **비슷한 로고를 지어내지 않고**, 받기 전까지는 글자 로고 "피클 Pickle"로 자리만 잡아둠
  → **사장님 휴대폰의 피클 앱 아이콘 / 앱 화면 캡처**를 주시면 로고·대표 색을 그대로 반영 (레지스트리 한 곳만 바꾸면 전체 교체)
- Apple·Google 로고는 권리 확인 전까지 쓰지 않고 "App Store / Google Play" 글자로 표기

## 4. 정확성 원칙 (지시서 5장 + 채널 규칙)
- 모든 앱 화면에 **"기능 설명용 재구성 화면"** 표시. 가격·상품·업체는 **"예시 수치"** 표시
- 결제 완료 / 서류 발급 완료 / SNS 자동 게시 / 통화 성공 장면은 만들지 않음 → "준비·확인·승인" 단계까지만
- 전화는 **피클이 거는 전화**(발신)로만 표현. 가게로 오는 전화를 받는 기능처럼 보이지 않게
- 정부 서류: "발급처 탐색·신청 보조", 본인인증은 직접
- 요금: 촬영 시점 기준 표기 + 공식 앱에서 확인 권장
