# 실험 #001 대본: 최종본 (5분)

**제목:** 신발세탁소 사장이 AI로 가게 앱 직접 만들었습니다 (러버블 사용법·비용 공개)
**썸네일:** A안 (`ThumbDynamicA.png`)
**길이:** 대사 약 1,200자(공백 제외). 차분하게 읽으면 4분 안팎이고, 화면 시연 사이에 쉬는 시간과 인트로까지 합치면 약 5분입니다.

> **굵은 글씨** = 자막에서 노란 형광펜으로 자동 강조되는 말
> S번호 = 스토리보드 장면 (영상에서 자동으로 바뀜)

---

## 녹음용 대사 (그대로 읽기)

### ① 훅 (S01)
```
저는 신발세탁소 사장입니다. 코딩은 한 줄도 모릅니다.
그런데 이 접수 시스템, 문자 발송, 손님용 앱까지, 제가 직접 만들었습니다.
어떻게 만들었는지, 돈은 얼마나 들었는지, 5분 안에 다 보여드릴게요.
```
⏸ **여기서 2초 쉬기** (채널 인트로가 들어가는 자리)

### ② 왜 만들었나 (S03 → S04)
```
신발세탁소, 생각보다 손이 많이 가요.
접수는 종이 장부에 쓰고, 입고 사진은 휴대폰 사진첩에 뒤죽박죽,
세탁 끝나면 한 분 한 분 문자 보내고, "제 신발 다 됐어요?" 문의도 계속 오죠.
이걸 6년 넘게 전부 손으로 했어요.
이거 프로그램으로 해결할 수 없을까? 그래서 찾은 게, 러버블이라는 AI입니다.
```

### ③ 러버블이 뭐예요? (S05 → S06)
```
러버블은 한마디로, 말로 설명하면 앱을 만들어주는 AI예요.
인테리어 업자한테 "여기 카운터, 여기 선반" 말로 설명하잖아요? 그걸 앱으로 하는 거예요.
화면 디자인, 손님 정보 저장, 인터넷 주소까지 알아서 만들어줘요.
챗GPT는 대답을 주고, 러버블은 바로 쓰는 앱을 줍니다.
```

### ④ 사용법 5단계 (S07 → S08 → S09)
```
사용법은 정말 간단해요. 딱 다섯 단계예요.
첫째, lovable.dev에 들어가서 구글 계정으로 가입. 1분이면 끝나요.
둘째, 만들고 싶은 걸 그냥 말로 써요. 제가 처음 쓴 문장은 이거예요.
"신발세탁소에 접수 시스템을 만들고 싶어. 먼저 기획부터 해줘."
바로 만들어달라고 하기보다, 이렇게 기획부터 부탁하면 필요한 기능을 먼저 정리해줘서 훨씬 편해요.
셋째, 조금 기다리면 오른쪽에 앱이 생겨요.
넷째, 마음에 안 들면 "버튼 더 크게 해줘", 이렇게 말로 고치면 돼요.
다섯째, 게시 버튼을 누르면 인터넷 주소가 생기고, 손님한테 바로 보낼 수 있어요.
```

### ⑤ 크레딧과 비용 (S10 → S11)
```
제일 궁금하실 돈 얘기. 러버블은 크레딧으로 써요.
AI한테 한 번 시킬 때마다 크레딧이 빠집니다.
무료는 하루 5개, 유료 Pro는 한 달 25달러에 100개부터 시작해요.
저는 한 달 동안, 총 100만 원 정도 들었어요.
솔직히 다시 만든다면 크레딧을 훨씬 아낄 수 있을 것 같아요.
크레딧 아끼는 팁은, 한 번에 하나씩 요청하는 거예요. 한꺼번에 시키면 꼬여서 고치느라 더 들어요.
그래도 6년 넘게 손으로 하던 일들이, 한 달 만에 전부 자동화됐어요.
```

### ⑥ 우리 가게 시스템 공개 (S12 → S13 → S14)
```
자, 이제 제가 만든 걸 보여드릴게요.
첫 번째, 접수. 손님 이름, 전화번호, 신발 종류, 서비스, 금액만 넣으면 접수번호가 자동으로 나와요.
종이 장부는 이제 안 써요.
두 번째, 사진 관리. 입고 사진, 완료 사진이 접수번호별로 정리돼요. 이제 사진첩 뒤질 일이 없어요.
세 번째, 문자 발송. 세탁 끝나고 완료 버튼 하나 누르면, 손님한테 문자가 자동으로 가요.
그리고 제일 뿌듯한 거, 손님용 앱.
손님이 문자 링크로 들어와서, 내 신발이 어디까지 됐는지 직접 확인해요.
정리하면, 접수, 사진, 세탁, 완료 문자, 손님 확인까지, 한 흐름으로 이어져요.
```

### ⑦ 솔직 결산 (S15)
```
솔직하게 말씀드릴게요.
예전엔 불가능했던 것들이, 이제 전부 시스템으로 가능해졌어요.
서비스 질이 좋아지니까 손님들도 편하게 생각하시고, 손님도 더 늘었어요.
아쉬운 점이요? 아직은 없어요.
한 줄로 정리하면, 러버블 AI를 쓰면, 불가능한 것들이 가능해진다!
```

### ⑧ 엔딩 (S16)
```
여러분 가게엔 어떤 기능이 있으면 좋겠어요? 댓글로 알려주시면 다음 실험으로 만들어볼게요.
다음 실험은, 어사이드 브라우저를 쓰면서 달라진 점입니다.
구독하고 같이 실험해요!
```

## 녹음 & SRT 가이드

**1. 녹음**
- 처음부터 끝까지 **한 파일**로 녹음하세요. 휴대폰 녹음도 괜찮아요.
- 훅 다음에 **2초 쉬기**. 인트로가 들어가는 자리예요.
- 틀리면 멈추지 말고 그 문장만 다시 읽은 뒤, 편집 앱에서 틀린 부분을 잘라주세요.

**2. SRT 자막**
- 녹음 파일로 만든 SRT를 주세요. CapCut, Vrew 같은 앱의 자동 자막을 써도 돼요.
- 자막 한 줄은 **한 문장, 또는 두 줄 이내 길이**가 보기 좋아요.
- 장면은 자막 안의 **시작 문구**를 보고 자동으로 바뀌어요. 아래 문구가 자막에 들어 있으면 돼요. 오타가 있으면 그 장면 전환만 건너뛰고 나머지는 정상으로 나와요.

|---|---|
| S01 훅 | 저는 신발세탁소 |
| S03 고민 | 생각보다 손이 |
| S04 전환 | 프로그램으로 해결 |
| S05 러버블이란 | 러버블은 한마디로 |
| S06 비유 | 인테리어 업자 |
| S07 사용법① | 사용법은 |
| S08 사용법② | 둘째 |
| S09 사용법③~⑤ | 셋째 |

| S11 내 비용 | 한 달 동안 |
| S12 접수 | 제가 만든 걸 |
| S13 사진·문자 | 두 번째 |
| S14 손님앱 | 제일 뿌듯한 |
