# 실험 #001 대본 (5분 버전)

**제목:** 신발세탁소 사장이 AI로 가게 앱 직접 만들었습니다 (러버블 사용법·비용 공개)
**썸네일:** A안 확정 (`ThumbDynamicA.png`)
**길이:** 약 5분. 대사는 공백 빼고 약 1,100자라 읽는 데 3분 40초 안팎이 걸리고, 실제 숫자를 채우고 화면 시연 사이에 잠깐씩 쉬는 시간까지 합치면 5분이 됩니다.

> `[ ]` = 사장님 실제 숫자/문장으로 채우기. **굵은 글씨** = 자막 강조(노란 형광펜).
> S번호는 스토리보드 장면 번호입니다.
