## 2. 기획안의 검수 원칙 반영 (Docs 6장)
- 예시 화면은 항상 "시연용 재구성" 표시 · 가짜 점수표·성능 순위 없음 · "제가 써보니" 경험 표현
- 자막에서 Claude(일반 채팅)와 **Claude Code**(개발 도구) 구분
- Claude Code는 영상 **코드**를 만드는 역할, 렌더링은 별도 도구·검수 필요 표시
- 회원가입: 필수 개인정보 안내와 선택 광고 수신 동의 분리, 수신 거부 · QR 메뉴 "무조건 무료" 아님 · 발주: 비교와 최종 주문 분리
- 실제로 실행하지 않은 작업의 터미널 로그를 사실처럼 보여주지 않음
