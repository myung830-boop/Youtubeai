## 3. 확인할 것
1. **(선택) 대본 한 줄 추가 제안**: 두·세·네 번째는 "두 번째는…"으로 시작하는데 첫 번째가 없어요. "단골손님은…" 앞에 **"첫 번째는 단골 관리입니다."**를 넣으면 듣는 사람이 따라가기 쉬워요. 그대로 두셔도 화면에 ①~④ 번호를 띄워서 괜찮아요.
2. **썸네일**: 2편처럼 캐릭터 없이 갈까요, 사장님 캐릭터를 넣을까요?
3. **S08 실제 코드 보여주기**: 이 채널 영상이 실제로 Claude Code와 리모션으로 만들어지고 있어서, 그 진짜 코드 화면을 보여주면 신뢰가 확 올라가요. 써도 될까요?
4. **공정성**: 기획·제작을 돕는 저는 Claude예요. 대본이 사장님 경험 기준의 역할 분담이라 한쪽으로 기울지 않아요. 화면도 두 AI를 같은 크기·같은 비중으로 그릴게요.
5. **공식 로고**: ChatGPT·Claude 심볼은 대체 디자인이에요. 썸네일 주인공이니 공식 로고 파일이 있으면 주세요.
