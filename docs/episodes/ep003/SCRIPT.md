# 3편 대본: ChatGPT vs Claude, AI를 잘 쓰는 1인 식당은 어떻게 달라질까? (최종본 · 사장님 작성)

**길이:** 대사 약 1,560자(공백 제외) → 목소리 약 4분 30초, 완성 약 4분 40초

## 녹음용 대사

### ① 훅 (S01)
```
사장님들, 챗GPT랑 클로드를 잘 활용하면 혼자 운영하는 식당이 얼마나 달라질까요?
단골에게 직접 쿠폰을 보내고, 우리 가게 홈페이지에서 쿠킹클래스를 모집하고, 테이블 QR 메뉴도 직접 관리하는 겁니다. 식재료 발주 목록까지 정리된다면 어떨까요?
저는 실제 매장을 운영하면서 AI를 써본 경험을 바탕으로, 오늘은 이런 변화가 어떻게 가능한지 구체적으로 보여드리겠습니다.
```

### ② 두 AI의 역할 (S02)
```
제가 써보니 챗GPT는 무엇을 만들지 정리하고, 기능을 기획하고, 홍보용 이미지나 영상 콘티를 준비하는 데 만족도가 높았습니다.
반면 클로드, 특히 클로드 코드는 그 기획을 웹사이트나 관리 프로그램, 영상 모션그래픽으로 구현하는 데 강점을 느꼈고요.
물론 서로 못 하는 일이 있다는 뜻은 아닙니다. 제가 실제로 역할을 나누는 방식이라는 얘기입니다.
```

### ③ 상황 설정 (S03)
```
가령 혼자 식당을 운영한다고 해보죠.
```

### ④ 첫 번째 · 단골 회원·쿠폰 (S04)
```
단골손님은 생기는데 누가 자주 오는지, 어떤 손님에게 소식을 전할지 관리하기 어렵습니다.
계산대에 태블릿을 놓고 손님이 휴대폰 번호를 입력해 간단히 회원으로 등록할 수 있게 만든다면 어떨까요?
손님이 원할 때 재방문 쿠폰을 지급하고, 신메뉴나 휴무, 특별 행사 소식도 직접 전달할 수 있습니다.
다만 휴대폰 번호만 받는다고 무조건 홍보 문자를 보낼 수 있는 건 아닙니다. 개인정보 안내와 광고 수신 동의를 구분해 받고, 수신 거부도 처리해야 하죠.
```

### ⑤ 두 번째 · 홈페이지 (S05)
```
두 번째는 우리 식당만의 홈페이지입니다.
메뉴 소개와 예약 안내뿐 아니라, 일반인을 대상으로 하는 원데이 쿠킹클래스를 열고 신청서를 받을 수 있겠죠.
나중에 운영 노하우를 교육으로 만들거나 식당 가맹사업을 준비한다면, 관심 있는 사람의 상담 신청을 받는 창구로도 확장할 수 있습니다.
이 과정에서 챗GPT로 사이트 구조와 프로그램을 기획하고 이미지를 준비한 다음, 클로드 코드로 실제 웹사이트를 만들어 보는 거예요.
물론 가맹사업을 시작하려면 별도의 법적 절차와 준비가 필요합니다.
```

### ⑥ 세 번째 · QR 메뉴 (S06)
```
세 번째는 QR 메뉴입니다.
테이블에 작은 QR 코드를 붙여두면 손님이 자기 휴대폰으로 메뉴 사진과 가격을 볼 수 있죠.
품절 메뉴를 바로 숨기거나 오늘의 추천 메뉴를 바꾸는 것도 가능합니다.
외부 구독형 QR 메뉴 서비스를 사용하지 않고 우리 식당용 페이지를 직접 만들 수도 있습니다.
다만 직접 만드는 게 완전히 공짜라는 의미는 아닙니다. 서버와 도메인, 유지보수 비용은 확인해야 하고, 실제 주문이나 결제까지 연결하려면 추가 기능도 필요합니다.
```

### ⑦ 네 번째 · 식재료 발주 (S07)
```
네 번째는 매일 반복되는 식재료 발주입니다.
쌀, 고기, 야채, 양념을 매번 기억해서 주문하는 대신, 재고를 기록하면 부족한 품목이 자동으로 구매목록에 올라가게 만들 수 있습니다.
여러 거래처 가격을 정리하고, 수량이나 배송비까지 비교하도록 기획할 수 있겠죠.
쇼핑몰과 연결할 수 있다면 자주 사는 품목을 장바구니로 넘겨 한 번에 확인하는 방식도 가능합니다.
다만 모든 사이트를 자동 연결할 수 있는 건 아니고, 가장 싼 가격을 항상 찾아준다는 보장도 없습니다. 최종 구매는 사장님이 확인하고 결정해야 합니다.
```

### ⑧ 두 AI의 역할 분담 (S08)
```
여기서 두 AI의 역할이 나뉩니다.
저는 챗GPT에 먼저 "1인 식당에서 가장 시간을 잡아먹는 일을 정리하고, 우선순위를 세워줘"라고 부탁합니다.
회원관리, 홈페이지, QR 메뉴, 발주 목록 중 무엇부터 만들지 결정하는 거죠.
그다음 기능 설명서를 클로드 코드에 전달해 실제 작동하는 화면과 코드를 만듭니다.
홍보 이미지는 챗GPT로 시안을 잡고, 가게 소개 영상은 챗GPT가 콘티를 짠 뒤 클로드 코드와 리모션 같은 도구로 모션을 구현할 수도 있습니다.
```

### ⑨ 현실 체크 (S09)
```
물론 AI를 활용한다고 갑자기 손님이 늘거나 식재료가 무조건 싸지는 건 아닙니다.
프로그램을 만들고 테스트하고 유지보수하는 시간도 들고, 고객정보를 다룬다면 동의와 보안도 중요합니다.
```

### ⑩ 그래도 매력적인 이유 (S10)
```
그렇지만 혼자 운영하는 사장님이 그동안 비용이나 기술 때문에 시도하지 못했던 일들을 하나씩 직접 기획해 볼 수 있다는 점이 저는 정말 매력적이라고 생각합니다.
```

### ⑪ 엔딩 (S11)
```
처음부터 네 가지를 다 만들 필요는 없습니다. 단골 쿠폰 하나, QR 메뉴 하나부터 시작해 보세요.
여러분 가게라면 어떤 업무를 가장 먼저 바꾸고 싶으신가요?
댓글로 업종과 고민을 알려주세요.
오늘부터 AI 사장님이었습니다.
```
