# 실험 #002 대본: 어사이드 브라우저로 가게 자동화하기 (5분)

**제목(추천):** 하루 2시간 걸리던 가게 컴퓨터 일, AI 브라우저로 5분 만에 끝냅니다 (어사이드)
**썸네일:** "하루 2시간 → 5분" + "AI 브라우저" + 어사이드 배지 크게, 캐릭터는 커피 들고 기대 있음, 커서가 혼자 움직임
**길이:** 대사 약 1,150자 → 화면 시연 포함 약 5분

`[ ]` = 사장님이 실제 문장/내용으로 바꿀 곳. `(예)`로 표시된 시킨 문장은 실제로 쓴 문장으로 바꿔 읽어주세요.

---

## 녹음용 대사

### ① 훅 (S01)
```
하루 2시간 걸리던 컴퓨터 일이, 이제 5분이면 끝납니다.
지금 화면 보세요. 저 손 하나도 안 대고 있는데, 홈택스에서 세금계산서가 알아서 입력되고 있죠.
오늘은 이걸 해준 AI 브라우저, 어사이드를 보여드릴게요.
```
⏸ 2초 쉬기 (인트로 자리)

### ② 남은 고민 (S02)
```
지난 영상에서 러버블로 가게 시스템을 만들었잖아요.
그런데 가게 일 중엔, 다른 사이트에서 해야 하는 일도 많더라고요.
택배 사이트 들어가서 보낼 물량 하나하나 입력하고,
네이버 블로그에 글 올리고, 인스타 피드 올리고,
홈택스 들어가서 세금계산서까지.
이런 인터넷 창 일만 하루 2시간이었어요.
```

### ③ 어사이드가 뭐예요? (S03)
```
어사이드는 한마디로, 인터넷 창을 자동화해주는 AI 브라우저예요.
말로 시키면, 알아서 사이트를 옮겨 다니면서 클릭하고 입력해줘요.
러버블이 가게 시스템을 만들어주는 AI라면,
어사이드는 여러 사이트에서 대신 일해주는 AI 직원이에요.
```

### ④ 시작하기 + 비용 (S04)
```
시작은 간단해요. 어사이드를 설치하고, 평소 쓰는 사이트에 로그인해 두고,
옆 채팅창에 말로 시키면 끝이에요.
비용도 부담 없어요. 챗GPT나 클로드를 이미 구독하고 있다면,
연결해서 추가 비용 없이 쓸 수 있어요.
```

### ⑤ 실전 ① 택배 (S05)
```
첫 번째, 택배 발송.
(예) "택배 사이트에 로그인해서, 오늘 보낼 물량 접수해줘."
이렇게 시키면 택배 사이트에 들어가서, 받는 분 정보랑 물품을 하나씩 입력해요.
제일 귀찮던 일이 제일 먼저 사라졌어요.
```

### ⑥ 실전 ② 블로그·인스타 (S06)
```
두 번째, 블로그랑 인스타.
(예) "오늘 세탁한 신발 사진으로 블로그 글 올리고, 인스타 피드도 올려줘."
글을 쓰고, 사진을 올리고, 올리기 전에 저한테 확인을 받아요.
홍보는 꾸준히 해야 하는데, 이제 미룰 일이 없어요.
```

### ⑦ 실전 ③ 홈택스 (S07)
```
세 번째, 제일 놀랐던 홈택스.
(예) "이번 달 거래 내역으로 세금계산서 입력해줘."
홈택스 화면을 알아서 넘기면서, 거래처랑 금액을 채워 넣어요.
발행 버튼은 제가 마지막에 확인하고 눌러요.
```

### ⑧ 보너스 쇼핑 (S08)
```
보너스로, 가게 물건 쇼핑도 시켜봤어요.
(예) "[살 물건] 찾아서 장바구니에 담아줘."
로그인된 네이버에서 알아서 찾아서, 장바구니에 담아두더라고요.
결제는 제가 직접 해요.
```

### ⑨ 솔직 결산 (S09)
```
정리하면, 하루 2시간 걸리던 인터넷 창 일이 5분으로 줄었어요.
어사이드는 알아서 사이트를 옮겨 다니니까, 귀찮은 일은 다 맡길 수 있어요.
아쉬운 점은 [아쉬운 점].
그리고 하나만 기억하세요. 결제나 발행처럼 중요한 버튼은, 꼭 직접 확인하고 누르세요.
```

### ⑩ 엔딩 (S10)
```
여러분은 AI 직원한테 어떤 일을 맡기고 싶으세요? 댓글로 알려주세요.
다음 실험은 [다음 주제]입니다. 구독하고 같이 실험해요!
```

- **네이버 쇼핑**: 배송지 주소, 이름, 전화번호, 포인트·결제수단
