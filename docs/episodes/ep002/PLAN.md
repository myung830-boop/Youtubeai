### 어사이드(Aside) 기본 정보 (확인된 범위)
- AI 에이전트가 들어 있는 크롬 계열 브라우저. 로그인해 둔 사이트에서 **클릭·입력·이동을 대신** 함
- 비밀번호는 AI에게 보여주지 않고 화면에 채워 넣는 방식, 결제·게시 같은 민감한 동작은 **사용자 승인** 후 진행
- 한국인 3인이 창업한 Y Combinator 스타트업. 맥 먼저 출시, 윈도우판은 2026년 9월 출시로 알려짐
- 요금은 출처마다 달라서 **사장님 실제 요금으로** 넣기 (공식 페이지 확인 필수)
- 이용약관에 숨은 지시문(프롬프트 인젝션)을 완전히 막지 못한다고 명시 → 영상에서 주의점으로 다룸

## 1. 제목·썸네일 후보
**제목**
1. 손 안 대고 가게 일 끝내는 AI 브라우저, 어사이드 써봤습니다 ← 추천
2. AI 직원 한 명 뽑았습니다 (어사이드 브라우저로 가게 자동화)
3. 러버블로 만들고, 어사이드로 굴린다. 신발세탁소 자동화 2탄

**썸네일 (A안 스타일 유지)**
- 1줄: "손 안 대고" / 노란 박스: **가게 일 자동화** / 3줄: "AI 브라우저"
- 캐릭터가 커피 들고 의자에 기대 있고, 화면 속 커서가 혼자 움직임 (보라색 빛 + 속도선)
- 오른쪽 위 어사이드 배지 크게, 실험 #002 태그

## 2. 구성 (약 5분)
| 시간 | 파트 | 내용 | 모션 연출 아이디어 |
|---|---|---|---|
| 0:00 | 훅 | "지금 저 손 안 대고 있습니다." 화면 속 커서가 혼자 리뷰 답글을 달고 접수를 입력 | 캐릭터가 두 손 들고 "저 안 만져요!", 커서가 빛나며 혼자 움직임 |
| 0:15 | 인트로 | 채널 인트로 | |
| 0:17 | 지난 실험 + 남은 고민 | 러버블로 시스템은 만들었는데, 여전히 사이트 여러 개를 왔다 갔다 함 (예약 확인 → 내 앱에 입력, 리뷰 답글, 홍보글) | #001 접수 앱 등장, 브라우저 탭 10개가 쌓이고 캐릭터 땀 |
| 0:45 | 어사이드가 뭐예요? | "말로 시키면 브라우저를 직접 조작하는 AI 직원" | 커서에 'AI 직원' 명찰, 러버블 vs 어사이드 비교 카드 |
| 1:20 | 시작하기 | 설치 → 사이트 로그인 → 옆 채팅창에 말로 시키기 → 민감한 동작은 승인 | 단계 배지 4개, 승인 버튼 클릭 |
| 1:55 | 실전 ① | (예) 네이버 예약·주문 확인해서 내 접수 앱에 대신 입력 | 화면 두 개를 오가며 커서가 복사·붙여넣기, 전후 시간 카운터 |
| 2:35 | 실전 ② | (예) 플레이스 리뷰 읽고 답글 초안 → 사장님 확인 후 등록 | 리뷰 카드가 줄줄이 넘어가며 답글이 채워짐 |
| 3:15 | 실전 ③ | (예) 매일 아침 루틴: 어제 접수·리뷰·문의 요약 보고 | 시계가 아침 9시 → 보고서 카드 도착 |
| 3:55 | 비용과 주의점 | 실제 요금 / 결제·게시는 꼭 승인 / 개인정보·비밀번호 / 수상한 페이지 주의 | 자물쇠·방패 아이콘, 승인 도장 |
| 4:25 | 솔직 결산 | 좋았던 점, 아쉬운 점, 한 줄 평 | #001과 같은 불가능 → 가능 톤 |
| 4:50 | 엔딩 | 다음 실험 예고 + 댓글 유도 | |

## 3. 대본 초안 (사장님 실제 경험으로 바꿀 부분은 [ ])
```
① 훅
지금 저, 손 하나도 안 대고 있습니다.
그런데 화면 속에서 리뷰 답글이 달리고, 접수가 입력되고 있죠.
오늘은 이걸 해준 AI 브라우저, 어사이드를 보여드릴게요.

② 지난 실험 + 남은 고민
지난 영상에서 러버블로 가게 시스템을 만들었잖아요.
그런데 막상 써보니, 여전히 손이 가는 일이 남더라고요.
[예약 사이트]에서 주문 확인해서 제 접수 앱에 옮겨 적고,
리뷰 하나하나 답글 달고, [홍보글 올리기]까지.
사이트를 왔다 갔다 하는 일이 하루 [ ]분이었어요.

③ 어사이드가 뭐예요?
어사이드는 한마디로, 말로 시키면 브라우저를 직접 조작하는 AI예요.
러버블이 가게 시스템을 '만들어주는' AI라면,
어사이드는 그 시스템이랑 여러 사이트에서 '대신 일해주는' AI 직원이에요.
제가 로그인해 둔 사이트에서 클릭하고, 입력하고, 페이지를 넘기는 걸 대신 해줘요.

④ 시작하기
시작은 간단해요. 어사이드를 설치하고, 평소 쓰는 사이트에 로그인해 두고,
옆에 있는 채팅창에 말로 시키면 돼요.
결제나 글 올리기처럼 중요한 건, 꼭 제가 승인 버튼을 눌러야 진행돼요.

⑤ 실전 ①
첫 번째, [예약·주문 옮겨 적기].
제가 이렇게 시켰어요. "[실제로 시킨 문장]"
그러면 어사이드가 [사이트]를 열어서 확인하고, 제 접수 앱에 하나씩 입력해요.
손으로 하면 [ ]분 걸리던 게, [ ]분으로 줄었어요.

⑥ 실전 ②
두 번째, [리뷰 답글].
"[실제로 시킨 문장]"
리뷰를 읽고 답글 초안을 달아주면, 저는 확인만 하고 등록 버튼을 눌러요.

⑦ 실전 ③
세 번째, [매일 아침 루틴].
"[실제로 시킨 문장]"
아침마다 어제 [접수, 리뷰, 문의]를 정리해서 알려줘요.

⑧ 비용과 주의점
요금은 [실제 요금제와 금액]이에요.
주의할 점도 있어요. 결제나 글 올리기는 꼭 직접 확인하고 승인하세요.
그리고 처음 보는 수상한 사이트에서는 AI에게 일을 맡기지 않는 게 좋아요.

⑨ 솔직 결산 + 엔딩
좋았던 건 [ ], 아쉬운 건 [ ].
한 줄로 정리하면, "[한 줄 평]".
여러분은 AI 직원한테 어떤 일을 맡기고 싶으세요? 댓글로 알려주세요.
다음 실험은 [다음 주제]입니다. 구독하고 같이 실험해요!
```

## 5. 사장님이 알려주실 것
- 실제로 어사이드에 맡긴 일 2~3개, 그리고 시킨 문장
- 쓰는 사이트 (예: 네이버 스마트플레이스·예약, 당근, 인스타 등)
- 전후 시간 (하루 몇 분 → 몇 분)
- 쓰는 요금제와 한 달 비용, 맥/윈도우
- 좋았던 점, 아쉬웠던 점, 한 줄 평, 다음 실험 주제
- 화면 녹화: 어사이드가 혼자 움직이는 장면 (고객 정보는 가짜 데이터로)
