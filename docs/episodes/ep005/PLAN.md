## 3. 대화형 실사용 장면 5곳
녹음은 사장님 내레이션 하나. **사장님 말 = 내레이션 + 말풍선**, **클로드 답 = 채팅 말풍선(글자) + 타이핑 효과음**.
화면은 숏-리버스숏·어깨 너머·모니터 속 시점으로 주고받는 느낌을 냄.

## 5. 정확성 원칙 (지시서 검수 메모 반영)
- Windows·Claude 앱 화면은 **"설명용 재구성 화면"** 표시. 메뉴 위치는 버전·요금제에 따라 다를 수 있음 표기
- **Claude Code는 지원 유료 요금제 필요**, 데스크톱 앱에 포함 — 녹음 그대로
- 음성 생성·렌더링은 **별도 도구·서비스**일 수 있고, 클로드는 설정을 돕는 역할 — 클로드 자체 기능처럼 과장하지 않음
- 설치·권한·비용은 사장님이 확인 (권한 창 [허용] 장면으로 표현)
- 카페 예시 영상은 **"제작 예시"** 표시. 1~4편 클립과 실제 대화는 사장님 실제 결과물
- 브랜드: Anthropic 후원·제휴처럼 보이지 않게, 로고는 변형 없이
